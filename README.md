# Text Classification using Multinomial Naive Bayes

This project classifies documents from the scikit-learn
20 Newsgroups dataset using a TF-IDF vectorizer and
a Multinomial Naive Bayes classifier.

## Files

- train.py
  - Downloads the dataset
  - Trains the model
  - Evaluates accuracy
  - Exports the trained model

- requirements.txt
  - Contains Python package dependencies

- 20newsgroups_model.joblib
  - Contains the trained ML model

## How to Run

Install dependencies:

pip install -r requirements.txt

Run the training file:

python train.py"# Text-Classification-and-Sericalisation"
